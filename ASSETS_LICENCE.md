# Asset licences — SHIFT IT!

**Code: MIT** (see `LICENSE`). **All art and audio: CC0 1.0 Universal (public domain).**

This repository is safe to make public. Every asset in it is either generated by the project's own
code or downloaded from a source that publishes it under CC0. **Nothing from a private or
non-redistributable library is committed or referenced.**

---

## Art — generated, not sourced

There is **not one imported image** in this repository. Every sprite in the game is produced at
runtime by `Assets/Scripts/Game/Shapes.cs` from rounded rectangles, circles, rings, triangles and
radial glows, and the four zone backdrops are assembled from those same primitives by
`ZoneBackdrop.cs`.

That makes the art original by construction, and it is released **CC0** along with the rest of the
assets.

| Asset | Origin | Licence |
|---|---|---|
| All sprites, robots, bombs, UI shapes, zone backdrops | generated in code at runtime | CC0 |
| Font | Unity's built-in runtime font (`LegacyRuntime.ttf`), shipped with the engine | Unity engine resource, not redistributed as an asset by this repo |

## What is deliberately NOT here

**Roy's private sound library (`D:\Desktop_Moved_20261020\KT_SoundLibrary`) is not used, and not
referenced.** It is Sonniss GDC content: cleared for use *in a shipped game*, but its licence says
*"Do not publish this folder as a downloadable library or bundle"* and standalone redistribution is
refused. Since GitHub Game Off requires a **public** repository, committing those files was never an
option, and a public repo that cannot build without files it does not contain would be a poor entry.

Also excluded on purpose:

- **No CC-BY assets**, so there is no attribution obligation that a future user of this repo could
  accidentally breach.
- **No asset-store content.**
- **No downloaded fonts.** The chunky display face planned for the game will be drawn as a generated
  sprite atlas rather than downloaded, for the same reason the sprites are generated.

## How to re-check this

```bash
# every file tracked by git, grouped by extension - should be text plus the five .ogg files
git ls-files | sed 's/.*\.//' | sort | uniq -c | sort -rn

# the only binary assets should be the five CC0 audio files
git ls-files | grep -iE '\.(wav|mp3|ogg|png|jpg|jpeg|exe|dll|zip|ttf|otf|fbx|psd|blend)$'
```
